Pourquoi Hagar-Auth

Minimaliste

Une interface sobre, sans fioritures, pensée pour rester lisible et efficace.

Sérieux

Des règles de sécurité claires, des validations précises et une logique sans effets inutiles.

Prêt à intégrer

Des fichiers HTML générés, un jeton API par projet et une API REST à utiliser sans surcharger votre code.

Fonctionnalités

Gestion de projets

Un Hagar par projet avec verrouillage par mot de passe optionnel.

Champs configurables

Définissez libellés, types requis ou non selon vos besoins.

Fichiers générés

Pages d'inscription et de connexion auto-construites à télécharger.

Jeton API rotatif

Régénérez la clé à tout moment pour révoquer l'ancien accès.

Liste utilisateurs

Consultez les identifiants inscrits avec leurs données configurées.

Protection API

Authentification par en-tête X-Hagar-Token et garde-fous contre l'abus.

Comment ça marche

  1. 01

    Créer un projet

    Configurez un nom et, au besoin, un mot de passe pour restreindre l'accès à votre Hagar.

    # Depuis l'interface
/compte > nouveau hagar
  2. 02

    Définir les champs

    Ajoutez les champs nécessaires (texte, email, mot de passe, etc.), indiquez l'obligatoire.

    champs: [email: requis, password: requis]
  3. 03

    Intégrer

    Téléchargez inscription.html et connexion.html, ou appelez l'API avec le jeton de votre projet.

    fetch('/api/hagar/login', {
  headers: { 'X-Hagar-Token': '<token>' },
  body: formData
})
